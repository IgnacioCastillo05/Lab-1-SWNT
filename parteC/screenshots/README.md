# Captura de pantalla pendiente

Esta carpeta es donde va la captura de pantalla pedida en el enunciado
("captura de pantalla del entorno de Cursor y Replit operando en
conjunto").

No se incluye una captura en esta entrega porque generarla requiere tener
Cursor y Replit abiertos en una pantalla real — algo que un agente de
código sin interfaz gráfica no puede producir de forma honesta. Ver
`docs/deployment-instructions.md` para el paso a paso de cómo generarla
en un par de minutos una vez que tengas ambas herramientas abiertas.

Cuando la tengas, guardala en este folder (ej. `cursor-replit.png`) y
actualizá el README principal si querés enlazarla desde ahí.

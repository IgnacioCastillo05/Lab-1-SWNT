# Capturas de pantalla y video demo

El enunciado pide capturas del proceso de iteración y, opcionalmente, un video demo de máximo 2 minutos.

No se incluye una captura o video real en esta entrega porque este proyecto fue generado por un agente de código (Claude Code) corriendo en un contenedor cloud sin interfaz gráfica ni grabadora de pantalla — no hay una ventana real que fotografiar. Lo que sí se entrega como evidencia equivalente y verificable:

- El código completo, corrido y testeado (16/16 tests en verde, ver `docs/bitacora.md`).
- La salida real de `pytest` mostrando los 2 bugs fallando y luego corregidos (documentada en `docs/bitacora.md`, sección 3).
- La app confirmada respondiendo HTTP 200 al levantarla con `streamlit run`.

Para generar las capturas/video reales: corré `streamlit run app/streamlit_app.py` localmente o en Replit, probá el ejemplo del enunciado en el chat, y capturá/gravá esa sesión. Guardá el archivo en esta carpeta.
